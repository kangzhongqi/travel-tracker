Ser vs Estar — 两个"是"

Ser = 本质/身份/永久特征。Estar = 状态/位置/临时情况。中文都翻译成"是"，但用错会让意思完全相反。

「我是开心的」— Soy feliz（我天性乐观）vs Estoy feliz（我现在开心）。一句"我很高兴"说 Soy feliz，西班牙人会以为你在表白人生哲学。
SERESTAR
🎂 身份/职业：Soy estudiante.😊 情绪/临时状态：Estoy cansado.
📅 时间：Son las tres.📍 位置：Está en la mesa.
🏠 来源/材料：Es de China.🔄 进行时：Estoy leyendo.
👤 性格/外貌：Es alto.👤 今天的状态：Hoy estás guapo.
判断法：加"现在/今天"更顺 → Estar。下定义"是什么"→ Ser。
La sopa es salada. → La sopa está fría.
这汤是咸的（做法如此）→ 这汤凉了（现在状态）

Por vs Para — 两个"为了"

Para = 目的地/目标（箭头 →）。Por = 原因/动机（箭头 ←）。

PARA（目标）POR（原因）
🎯 目的：Estudio para aprender.💭 原因：Lo hago por ti.
📅 截止：Para el lunes.⏰ 时间段：Por la mañana.
🚗 方向：Voy para Madrid.🛤️ 途径：Paso por Madrid.
👤 接收者：Es para ti.💰 交换：Lo compré por 10€.
📐 对比：Para su edad...🙏 感谢：Gracias por venir.
Para = for the purpose of。Por = because of / through / in exchange for。

简单过去时 vs 过去未完成时

A2 最大的坎。Indefinido = 完成的动作/事件。Imperfecto = 背景/习惯/持续状态。

中文没有时态变形，所以中国学习者下意识用错了也感觉不到。关键训练：看到"了"、"完"→ Indefinido；看到"在"、"着"、"以前常常"→ Imperfecto。
INDEFINIDO（点）IMPERFECTO（面）
✅ 一次性完成：Ayer fui al cine.🔄 习惯：Iba al cine cada día.
📅 具体时刻：A las 8 llegué.🌅 背景：Eran las 8, hacía sol.
🔗 动作链：Entré, miré, salí.⏸️ 同时进行：Mientras comía, leía.
🧠 状态改变：Supe la verdad.（那一刻知道了）🧠 持续状态：Sabía la verdad.（当时一直知道）
电影思维：Indefinido = 镜头里发生的动作。Imperfecto = 镜头的背景和氛围。
Cuando entré, llovía.
我进来时（一个动作），天在下雨（持续背景）
同一句话里两时态配合 — A2 核心考点

宾格代词 & 与格代词 — lo/la/le 到底怎么分

Duolingo 头号难题。简单说：lo/la = 动作的直接对象（把谁怎么了），le = 动作的间接对象（给谁/为谁）。

宾格 (直接宾语)与格 (间接宾语)
我meme
你tete
他/它lole (→ se 如果和 lo 连用)
她/它lale
我们nosnos
他们/它们los / lasles (→ se 如果和 lo 连用)
记住：lo/la = 替代"什么"。le = 替代"给谁"。
¿El libro? Lo leí. / ¿A María? Le di el libro.
中国学习者最常见的错误：该用 le 的地方用了 lo。比如 *Lo di el libro 是错误的（应该是 Le di el libro）。判断法：把宾语换成"他"→ 如果能变成"给他"就是 le，如果只是"他"就是 lo。
Se lo di.
我把它给他了。（le + lo → se lo，因为 le lo 发音别扭）
le + lo/la → se lo/la 是强制规则，不是可选的

命令式 — 怎么叫人做事情

A2 日常必需。点餐、问路、给指令都靠它。分肯定命令和否定命令，tú 和 usted 的变形规则完全不同。

人称-AR (hablar)-ER (comer)-IR (escribir)
tú (+)hablacomeescribe
tú (−)no hablesno comasno escribas
usted (+)hablecomaescriba
ustedes (+)hablencomanescriban
记忆口诀：tú 肯定 = 去掉 r（hablar→ habla，但 decir→ di 等不规则例外）。tú 否定 = 把现在时 yo 的 o 换成 as/es。usted = yo 形的 o 换成 e/a。
¡Come! / ¡No comas!
吃！/ 别吃！
¡Hable más despacio, por favor.
请您说慢一点。（usted 命令，礼貌请求）

将来时 — ir a + infinitivo

A2 最实用的时态。比真正的将来时（comeré, hablarás）更日常、更简单：ir 的现在时 + a + 动词原形。

人称ir 变位例句
yovoy aVoy a estudiar. 我要学习。
túvas a¿Vas a venir? 你要来吗？
él/ellava aVa a llover. 要下雨了。
nosotrosvamos aVamos a comer. 我们去吃饭。
ellosvan aVan a llegar tarde. 他们会迟到。
千万别把 ir 变复杂了 — 它就是 voy/vas/va/vamos/vais/van，后面永远接 a + 动词原形。等于英语的 going to。
Este fin de semana voy a visitar a mis abuelos.
这个周末我要去看爷爷奶奶。

比较级 & 最高级

结构非常规律：más/menos + 形容词 + que = 比…更/不如。

类型结构例句
更…más + adj + queEres más alto que yo.
不如…menos + adj + queEs menos caro que ese.
一样…tan + adj + comoEs tan inteligente como tú.
最多el/la más + adjEs el más grande.
四个不规则比较词必须背：bueno → mejor（更好），malo → peor（更差），grande → mayor（更大/年长），pequeño → menor（更小/年幼）。Duolingo 经常考。

虚拟语气入门 — A2 阶段只需知道这些

虚拟语气（subjuntivo）B1 才系统学，但 A2 已经遇到几个固定表达，先记住即可。

触发词后面接例句
Ojalá虚拟现在时¡Ojalá llueva! 但愿下雨！
Quizás / Tal vez虚拟现在时Quizás venga mañana. 也许他明天来。
Cuando + 将来虚拟现在时Cuando tenga dinero, viajaré. 等我有钱了就去旅行。
Para que虚拟现在时Te lo digo para que sepas. 我告诉你让你知道。
A2 对策：记住这四个触发词，变形规则就是 -AR 用 -ER 词尾（hable/hables/hable…），-ER/-IR 用 -AR 词尾（coma/comas/coma…）。

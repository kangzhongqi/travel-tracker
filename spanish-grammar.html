⚡ Ser vs Estar — "是"的两个面孔

中文都翻译成"是"，但西语严格区分：Ser = 本质/身份，Estar = 状态/位置。用错会让句子意思完全不同。

SER — 本质、永久ESTAR — 状态、临时
🎂 身份/职业：Soy profesor.
我是老师（我的职业）		😊 情绪/状态：Estoy cansado.
我累了（暂时的）
📅 时间/日期：Hoy es lunes.
今天是周一		📍 位置：Estoy en casa.
我在家
🏠 来源/材料：Es de madera.
是木头做的		🔄 进行时：Estoy comiendo.
我正在吃
👤 特征：Eres muy alto.
你很高（天生）		👤 临时特征：Estás muy guapo.
你今天很帅（打扮了）
一个词判断：如果加了"现在/今天/正在"更通顺 → 用 Estar。如果是在定义"是什么" → 用 Ser。
Soy feliz. vs Estoy feliz.
我是幸福的人（性格乐观） vs 我现在很开心（遇上好事了）
同样一个 feliz，用 ser 和 estar 意思完全不同！

🧭 Por vs Para — 两个"为了"怎么分

最简单的记忆法：Para = 目标/目的地（向前看），Por = 原因/途径（回头看）

PARA — 目的、终点POR — 原因、途径
🎯 目的：Estudio para aprender.
我学习是为了学会		💭 原因：Lo hago por ti.
我这么做是因为你
📅 截止时间：Para el lunes.
周一之前		⏰ 时间段：Por la mañana.
在早上（泛指）
🚗 方向/目的地：Voy para Madrid.
我去马德里		🛤️ 经过/途径：Paso por Madrid.
我经过马德里
👤 接收者：Es para ti.
这是给你的		💰 交换：Lo compré por 10€.
我花 10 欧买的
📐 对比标准：Para su edad...
考虑到他的年龄…		🙏 代办：Gracias por venir.
谢谢你来
Para = 箭头 → 指向未来目标。Por = 箭头 ← 回头看动机。

⏳ 简单过去时 vs 过去未完成时

Duolingo 里最让人头疼的选择。一句话总结：Indefinido = 完成的动作/事件，Imperfecto = 背景/习惯/进行中的状态

INDEFINIDO (简单过去时)IMPERFECTO (过去未完成时)
✅ 一次性完成的动作：Ayer fui al cine.
昨天我去了电影院		🔄 过去的习惯：Iba al cine todos los días.
我以前每天去电影院
📅 具体时间点：A las 8 llegué.
8 点我到了		🌅 背景描述：Eran las 8, hacía sol.
当时 8 点，天气晴朗
🔗 连续动作链：Entré, miré, salí.
我进去，看了看，出来了		⏸️ 同时进行的动作：Mientras comía, leía.
他一边吃一边读
🧠 状态改变（开始/结束）：Supe la verdad.
我知道了真相（那一刻）		🧠 持续状态：Sabía la verdad.
我（当时）知道真相
电影思维：Indefinido = 镜头里发生的"动作戏"。Imperfecto = 镜头里的"布景和氛围"。
Cuando entré, llovía.
当我进来时（一个动作），天在下雨（持续背景）
同一句话里两个时态配合：动作用 Indefinido，背景用 Imperfecto

🧠 Saber vs Conocer — 两个"知道"

Saber = 知道信息/会做某事，Conocer = 认识人/地方/事物（有过接触了解）

SABER — 知识、技能CONOCER — 认识、熟悉
📚 知道事实：Sé que es tarde.
我知道很晚了		👤 认识人：Conozco a María.
我认识 María
🎵 会做某事 (saber + inf)：Sé nadar.
我会游泳		🏙️ 熟悉地方：Conozco Madrid.
我熟悉马德里（去过）
📖 记得内容：¿Sabes la respuesta?
你知道答案吗？		📖 听说过/接触过：¿Conoces este libro?
你知道这本书吗？（读过/见过）
Saber 后面可以接 que / si / 疑问词 / 动词不定式。Conocer 后面直接接名词或 a + 人。
Sé quién es, pero no lo conozco.
我知道他是谁（有信息），但我不认识他（没接触过）
同一句话里两个"知道"的区别一目了然
